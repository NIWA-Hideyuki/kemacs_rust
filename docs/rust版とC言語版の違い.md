# Rust 版と C 言語版の違い

このドキュメントは、kemacs の **Rust 版** と元の **C 言語版** を比較したものです。C 版のソースとビルド・テストは別リポジトリで管理されています。

基本方針は「できるだけ C 版の使用法に合わせる」ことです。キーバインド・起動オプション・スタートアップファイル・モードライン書式を C 版に合わせ、**どうしても合わせられない項目には理由を明記**します。

実装範囲の詳細は [`Rust移植.md`](Rust移植.md)、操作の詳細は [`kemacs使用手引書.md`](kemacs使用手引書.md) を参照してください。

---

## 1. C 版に合わせた項目

| 項目 | 変更内容 |
|---|---|
| `C-X @` (pipecmd) / `C-X #` (filter) | Rust 版に実装済みのコマンドへキーを割り当てた |
| `C-X D` (bktoshell) / `M-S` (bktoshell) / `M-C-E` (execproc) | 同じく既存コマンドへキーを割り当てた |
| `-v` / `-V` | VIEW モード (読み取り専用) にする |
| `-e` / `-E` | EDIT モード (既定) を明示 |
| `-b` / `-B` | BINARY モード。文字コード・改行の変換を停止する |
| `-g<line>` | 起動時に指定行へ移動 |
| `-x<command>` | 起動時にコマンドを実行 |
| `-f<code>` / `-t<code>` | 文字コードを指定 (`--code` と同じ) |
| `-r` / `-R` | 制限モード。ファイル操作・シェル実行を禁止する |
| `-s[<pattern>]` | 起動時検索。raw mode 開始後に実行する |
| `-k[<key>]` | 暗号キー設定。raw mode 開始後に実行する |
| `@file` | スタートアップマクロを実行 |
| `~/.kemacsrc` | 起動時に自動実行するようになった |
| モードライン `%t` / `%T` | libc `localtime_r()` によるローカル時刻 (`HH:MM`) |
| モードライン `%<` / `%>` | `reclevel` (再帰編集・マクロの深さ) に応じて繰り返す |
| `$gmodeline` / `$bmodeline` | `$mode-line-format` の別名として読み書きできる |
| query-replace の `!` | 以降の一致を確認なしで置換する |
| query-replace の `^` | 直前の 1 件だけを取り消して再確認する (`u` も可) |
| 対話的変数 `@...` | 変数参照のたびにプロンプトで入力する |
| `M-X` の補完 | TAB / SPACE でコマンド名を補完し、候補を表示する |
| `auto-mode-for-file` | 正規表現パターンでファイル名からモードを自動設定 |
| `^C` | raw mode を解除して一時的にシェルへ脱出 |
| `JIS-NEW-ROMAJI` / `JIS-NEW-ASCII` / `JIS-OLD-ROMAJI` / `JIS-OLD-ASCII` | 新旧 JIS と ASCII/ローマ字のエスケープ序列を切替 |
| 検索・置換のキーワード入力 | ESC で確定する (改行では確定しない) |
| マウス中ボタン | クリック位置へクリップボードを貼り付ける |
| マウス横スクロール | `$wheel-lines` 件だけ左右へ移動 |

`C-X @` などのキーは、C 版の `ebind.H_` と機械比較して欠落が見つかった5件です。コマンド本体は Rust 版にすでに実装されており、割当てだけが不足していました。

起動オプションのうち `-s` / `-k` は、プロンプトを伴う操作が raw mode 開始前に端末制御へ衝突するため、`input::enable()` の直後にまとめて実行する `StartupAction` キューへ延期しました。値が付いていない場合は raw mode 開始後にプロンプトへ入ります。

## 2. 残る違いと、合わせられない理由

### 2.1 `$tcode` (端末コード)

C 版はファイルコードと独立して設定できましたが、Rust 版では `$bcode` の別名です。端末側の符号化方式を別管理すると、表示と保存のコードがずれるため、Rust 版は 1 本化しています。

### 2.2 外部ヘルプファイル

`emacs.hlp` / `emacs.tut` は同梱しません。`M-?` がキー割当てから組み込みでヘルプを生成するため外部ファイルが不要で、チュートリアルは本ドキュメント群で代替しています。

### 2.3 以前この節にあった未移植項目

`-s` / `-k`、BINARY の変換停止、制限モードのコマンド制限、query-replace の `^`、対話的変数、`M-X` 補完、`auto-mode-for-file`、`^C` シェル一時脱出、JIS 新旧切替、マウス中ボタン・横スクロール、ローカル時刻と再帰レベルは **すべて section 1 のとおり実装済み** です。

## 3. 誤解されやすい点 (実は共通)

以前の比較で差分として挙げられていたが、C 版の `ebind.H_` を確認した結果 **共通だった** 項目です。

| キー | C 版 | Rust 版 |
|---|---|---|
| `DEL` (0x7F) | backdel (後方削除) | backdel (後方削除) |
| `C-D` | forwdel | forwdel |
| `C-H` | backdel | backdel |
| `^X ^R` | redo | redo |
| `^R` | backsearch (逆方向検索) | backsearch |
| `M-G` | gotoline | gotoline |
| `M-N` | gotoeop (次の段落) | gotoeop |
| `M-C-N` | namebuffer (バッファ名変更) | namebuffer |

なお `^C` は、Rust 版のドキュメント (`kemacs使用手引書.md`) に従い「シェル一時脱出」として実装しました。参照した C ソース (3.7 系) の `ebind.H_` では `^C = exitrecedit` です。`exitrecedit` は Rust 版でも名前付きコマンドとして残しています。

## 4. 外観の違い (Rust 版の拡張)

これらは C 版に合わせると機能が失われるため、Rust 版の拡張として残しています。

| 項目 | C 版 | Rust 版 |
|---|---|---|
| 色 | 行単位、既定は `COLOR=0` (無効) | 文字単位、8 / 256 色 (Ansi) と truecolor (RGB)。`$fcolor` / `$bcolor` で設定 |
| Markdown conceal | なし | `^X Y` または `$md-conceal=1` で強調記号とリンク URL を描画時に非表示 |
| 暗号化 | C 互換の弱暗号 (DLH-POLY-86-B) | 弱暗号に加え、`M-x set-strong-key` で XChaCha20-Poly1305 + PBKDF2 の強暗号 |
| マウス | なし | SGR 1006 キャプチャを有効にし、ホイールでカーソル移動 (`$wheel-lines`、既定 3)、左ボタンでクリック/ドラッグ選択 (反転表示)、中ボタンで貼り付け、右ボタンのドラッグでコピー / 右クリックでペースト。クリップボードは OSC 52 + ブラケットペーストで端末と共有 |
| リサイズ | `tcap.c` の SIGWINCH | crossterm の Resize イベントを 50ms ポーリングし、全行を再描画 |
| 未編集ファイルの保存 | 再エンコードされる場合があった | 元バイト列をそのまま書き戻す |
| 表現不能文字 | 素通し | `KEMACS-U+XXXX;` 形式で保存し、読み込み時に復元 |

モードラインの既定書式は両版とも同じです。

```
== %p %v (%m) == %b == File: %F == %c %-
```

## 5. 移行時のポイント

1. `make` ではなく `cargo build` / `cargo run --` を使う。
2. `~/.kemacsrc` は自動実行される。ただし対話的なコマンドはマクロ中で使わないこと。
3. 起動オプションは C 版とほぼ同じ。`-s` / `-k` は raw mode 開始後に実行される。
4. `-b` は文字コード変換を停止し、`-r` はファイル操作・シェルを禁止する。
5. query-replace は `y/n/^/!/q` に対応。`^` は直前の 1 件だけを戻す。
6. `%t` はローカル時刻、`%<` / `%>` は再帰レベルに基づく。
7. 色・conceal・強暗号は Rust 版の拡張。C 版には無い。
8. 設定・キー・仕様の詳細は [`kemacs使用手引書.md`](kemacs使用手引書.md)、[`Rust移植.md`](Rust移植.md) を参照する。
